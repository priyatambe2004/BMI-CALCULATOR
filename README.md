# Veda Internship – Task 6: BMI Calculator

A responsive and interactive **BMI Calculator** developed as part of my **Veda Web Development Internship – Task 6**.

## 📌 About the Project

This project is a web-based BMI Calculator that allows users to calculate their Body Mass Index using either **Metric** or **Imperial** units.

The application provides the calculated BMI, BMI category, healthy weight range, personalized guidance, and a visual BMI indicator. It also stores recent calculations locally in the browser for convenient access.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API

## ✨ Features

* Metric unit support (cm, kg)
* Imperial unit support (ft, in, lb)
* BMI calculation and classification
* Input validation
* Validation for unrealistic height and weight values
* Healthy weight range calculation
* Visual BMI gauge
* Underweight, Normal Weight, Overweight, and Obese categories
* Personalized result advice
* Light and dark theme
* Recent calculation history
* Local storage for saving history and theme preference
* Reset functionality
* Responsive design
* Accessible form controls
* Reduced-motion support

## 📐 BMI Formula

```text
BMI = Weight (kg) / Height² (m)
```

For Imperial units, height and weight are converted to metric units before calculating BMI.

## 📊 BMI Categories

| BMI Range    | Category      |
| ------------ | ------------- |
| Below 18.5   | Underweight   |
| 18.5 – 24.9  | Normal Weight |
| 25 – 29.9    | Overweight    |
| 30 and above | Obese         |

> BMI is a general screening measure and is not a medical diagnosis.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Select Metric or Imperial units.
5. Enter your height and weight.
6. Click **Calculate BMI** to view the result.
